# Siranay Freight Management — Next.js Website

Custom, component-based Next.js build recreated from the supplied desktop references.

## Stack
- Next.js App Router
- React
- Plain CSS only
- No Tailwind CSS
- No Bootstrap
- No external UI framework
- Local WebP assets

## Main pages
- `/`
- `/services`
- `/about`
- `/carrier-inquiry`
- `/contact`
- `/privacy-policy`
- `/terms`
- `/disclaimer`

## Service pages
Generated from reusable service data under `/services/[slug]`, including dispatch services, carrier setup assistance, billing/invoicing support, broker communication, route coordination, cross-border support, load sourcing, ongoing carrier support, bilingual communication, and small-fleet support.

## SEO files
- `/robots.txt`
- `/sitemap.xml` (generated by `app/sitemap.js`)
- `/llms.txt`
- `/LLM.txt`
- Organization and Service JSON-LD
- Per-page titles, descriptions, canonicals, Open Graph metadata

## Run locally
```bash
npm install
npm run dev
```
Then open `http://localhost:3000`.

## Reference redesign — October 2026

The four supplied Home, Services, About and Carrier Inquiry references drive the compact navy/gold layout. Contact, service detail and legal routes use the same shared design. Desktop grids collapse at 900px and 640px. Generated photography is converted to WebP and stored in `public/images/`.

`npm run build` creates a portable static website in `out/`. Development uses `.next-dev/`, independently of production build output. `node verify-export.cjs` checks exported local links and image paths.

The local Sites registration is retained in `.openai/hosting.json`. Publication is not confirmed: the Sites plugin became unavailable during this session. The corrected hero and main desktop layouts were visually inspected at 1280px. The five main pages were checked at 390px with no horizontal overflow; mobile navigation and FAQ expansion passed. Generated photography closely follows the references but is not a pixel-identical copy.

- Hero (`hero-truck.webp` and page variants): recreate only the supplied Home screenshot's hero photograph; navy truck cab at right, silver trailer extending left, dark pine forest and mountain text space at left, visible golden sun at far right, wide 3:1 composition, no lettering or UI.

All briefs requested clean photographic assets without overlay text, badges or website interface elements.
